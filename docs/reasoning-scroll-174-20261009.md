# 流式思考自动滚动修复与 174 发布

思考内容展开后位于独立的 250px 滚动区域，原实现只有外层对话会跟随生成内容，内层思考停留在旧位置。本次让思考区域复用对话滚动控制器：生成时跟随底部，手动向上滚动或通过键盘阅读时暂停，回到底部恢复。内外滚动状态独立，完成时刷新最后片段并尊重手动阅读位置，已完成的历史思考打开后从起始位置阅读。

没有改变输入区、思考区域的尺寸和样式。上一版办公室麦克风采集调整保留；API、Worker、数据库和共享 ASR 服务没有变更。
