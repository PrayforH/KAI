# 产出物拖动边界与回复图片修复

正式入口 https://172.20.109.174/ 已更新，实现提交 `6a2fea2d72d2fdf0006ab997ad5ec9880b5412ae` 已推送 develop。此版本替代上一版允许面板持续挤压对话到仅剩 64px 的展开边界。

## 行为

桌面端普通分栏保留至少 480px 对话宽度；拖动超过边界时，立即预览完整展开，松手确认，避免留下半截正文和越界的输入框。向内缩至 180px 后立即预览收起，松手确认；Escape 取消展开或收起预览。导航栏较宽、无法同时容纳对话和至少 280px 预览时，直接展开；此时“还原对话区”会收起面板。窗口尺寸变化不会覆盖用户保存的普通面板宽度。

任务内容的网格列允许缩至可用宽度，修正长链接、图片和输入框在窄屏把内容区域撑宽的问题。输入框限制在所属对话列，层级与右侧面板隔离。会话继续挂载，保留输入和预览内容。

回复中根据 `harness_present_artifact` 元数据直接显示最终图片，适用于已加载的历史回复和新回复。保留图片比例，点击打开对应文件的全宽预览。过滤中间过程图片，去重重复事件及正文已经嵌入的同一图片；图片加载失败保留下载入口。修正主页面没有向文件面板传递选中文件请求的问题。
