# 主对话自动交互与展示修复验收

2026-10-14。本记录延续 `docs/intelligent-ui-natural-20261014/report.md` 的自然提问基准，加入回答前的 d1 引导，并修复用户提供截图中的四个展示问题。

## 已实现的行为

回答前由 d1-3B 返回严格的两个布尔字段：是否值得加入交互、是否需要真实照片。结果作为私有展示建议提供给主模型；组件、布局、输入参数和业务内容仍由主模型决定。没有改写用户输入，没有针对婚礼、自驾等案例写关键词分支。原后置 d1 表格/图表选型仍保留，两个调用共用一个有超时限制的客户端。

交互应直接完成可操作内容，计算、模拟、结构探索、规划勾选和游戏按业务选择。图片要进入最终正文及 HTML 的实际 `img` 元素，带说明和来源；进度消息里出现图片不计交付成功。模型先运行核心逻辑检查，发布工具再对最终 HTML 中的 JavaScript 做语法检查。检查只解析脚本，不执行模型代码；限制文件尺寸和检查时间，取消或超时会回收子进程。普通下载文件保持原发布路径。

## 四个展示问题

| 用户观察 | 原因与修复 | 验证 |
| --- | --- | --- |
| 思考/工具过程中出现孤立 `。` | 短标点候选不提前晋升为回答；工具进度中的纯标点不渲染。真实最终符号回答保留 | 实际样式组件与流状态回归 |
| 还在处理却出现“HTML 1 项产出” | 本轮消息与运行均结束后才显示产出行、图片和交互块；已完成历史轮次继续显示 | 双状态边界回归，历史完成与失败场景 |
| “正在恢复工具 / presentation not found” | 活跃历史不再暴露尚未持久化的交互块。读取缺失块时，仅从当前用户有权读取的终态运行重建，再校验同一 ID 和版本 | 冷恢复、越权、未结束运行的 API 集成测试；真实页面刷新 |
| 多轮时旧内容先闪回 | 新一轮等待服务端消息期间接管原生文本槽；旧轮保留清理后的回答，新消息不继承旧捕获值 | 重用消息槽回归；Chrome 真实续问约 7 秒完成，直接显示新的一句回复 |

恢复读取最多三次，仅重试暂时缺失、未就绪、网络中断和网关暂时失败。最终失败结束加载并提供中文说明与手动重试。动作提交和状态写入不自动重试。iframe 继续使用不透明脚本沙箱和每帧随机令牌，没有放开同源访问或任意网络请求。

## 自然提问与模型证据

实际运行共 21 次：174 的 12 次、79 的 9 次，其中 79 最后一次为多轮续问。首轮用户输入保留附件式自然问题，例如“GDP 是怎么算的？”、“要去意大利参加婚礼，帮我规划一周穿什么。”、“规划一趟太平洋西北部10天的自驾。”没有附加 HTML、组件种类、滑块或交互协议要求。

主模型实际为 deepseek-flash，模型路由从 `harness.runtime.v1` 核对。初版 174 的 8 个正例全部发布 HTML，问候与只要文字的两个负例没有交互块。仅发布成功不能代表所有交互逻辑正确：初版三门问题发现开门分支错误，随后加强逻辑验证并重新生成；不能将初版 8/8 发布率写成 8/8 完整功能同效。

初版婚礼 HTML 没有图片，自驾图片只在 Markdown；已修正展示建议。第三版婚礼出现模型抄错文件 ID，内联块被拒绝；自驾最终脚本有拼接语法错误。这些失败保留在结果记录中，未用后续成功替换它们。最终婚礼和自驾复测均发布有图片的 HTML，脚本独立解析通过，实时流与历史呈现快照一致。

分类边界：初版分账请求的 d1 交互字段为 false，主模型仍按用户要求发布了分账器。尝试增强风格与输出约束判断的提示词后，部分原理解释被误判为纯文字，候选版本已舍弃；`rejected-classifier-trial.json` 保留失败试验，生产继续采用完成真实对话验收的提示词。d1 提供建议，不作为交互生成的唯一条件。

## 真实页面验证

- 自驾：在 79 的实际聊天内联 iframe 中，勾选火山口湖后，天数 10 → 12、里程 1119 → 1589 英里、驾驶 28.3 → 37.8 小时。展开雷尼尔山日程看到了照片。刷新后保留支线选择和数值，没有 `presentation not found`。
- 婚礼：在实际内联 HTML 看到参考图及来源，图库共 6 张候选图，截图时 3 张实际可见。79 对这 6 个图片地址均读取并解码成功；用户浏览器仍可能因第三方来源网络条件而不能显示全部照片。一次临时快照读取失败后手动重试成功；最终版本加入有限网络自动重试，页面刷新恢复正常。
- 多轮：在婚礼对话中自然续问“请只用一句话概括上面的穿搭方案。”d1 返回交互=false、图片=false。运行中直接出现新的简短正文，结束后没有新产出行，也没有重放第一轮长文。

后端相关回归 295 项通过。前端全量 177 个测试文件、1164 项通过、1 项跳过。TypeScript、Python 相关模块类型检查、Ruff 和生产构建通过。两台服务器验证语法正确的恶意执行样例不会被执行，错误 HTML 脚本会被拒绝。服务健康检查通过。

测试提取任务全部完成。174 未从本次测试产生记忆；79 产生的两条新示例记忆已按精确测试 Run 来源转为待确认、保留内容与证据并记录审计。其他已有记忆和用户参考对话未修改。

## 验收边界

自动选择和生成交互的能力已经接入；这不保证每次模型生成的业务逻辑都与附件完全相同。语法检查能阻止最终脚本解析失败，但不能代替计算和状态分支测试。第三方照片仍可能拒绝或延迟访问。没有把 Markdown 图片引用数、HTML 发布数或模型自报测试数量当作全部功能通过率。
