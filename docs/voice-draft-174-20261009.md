# 实时语音草稿修复与 174 发布

连续讲话时，Nano 的 `partial` 只包含最近约 8 秒的滑动音频窗口。原实现将其当作完整草稿替换，前文因此消失，再在整句确认时恢复。现在按 `partial_start_ms` 衔接可靠的重叠文字，保留滑动窗口以前的内容；无法确定衔接位置时暂缓更新，已确认句子和最终识别结果仍为权威。每个会话独立维护状态。

输入框根据最小文字差异映射选区，在布局阶段恢复光标和滚动位置。阅读前文时暂停自动跟随，回到底部后恢复。相同草稿不重复更新。输入框和语音控件的尺寸、样式保持现有实现，文字增多时仍按普通输入框规则增加高度。

删除或修改已识别内容不再永久切断听写：跳过旧识别历史，从编辑位置继续填入新语音。停止后的全段文本精修不覆盖手动编辑，取消只回退编辑后的新语音片段。

续写修复的第一版曾逐次追加新识别内容，把临时句号固定下来，导致句号增多。最终版本改为替换、修正当前新增语音片段，后端同时暂缓显示未确认片段的句尾句号。已确认句子和最终结果的标点完整保留；识别模型仍可能修正未确认文字及内部标点。

实时识别仍使用 229:18013 的 Fun-ASR-Nano；文本精修仅在停止后调用一次。共享 ASR 服务、模型及三个 Worker 未变更。
