# 项目资源与技能复用

本批只增加三个入口，保持现有项目页、左侧导航及隐藏的成果卡片状态。

- 文件预览中的「加入项目资源」保存不可变产物快照并直接绑定项目文件。重复点击返回同一快照；后续任务继承该文件，不依赖来源任务是否归档。
- 项目任务菜单和产物预览中的「提炼为项目技能」读取当前用户、本项目任务的可见对话及可读文本产物，调用已有技能生成服务，先展示可编辑草稿。用户选择保存草稿或保存并启用。项目技能面板支持查看、启停和删除未启用草稿。
- 「搜索网页」是独立弹窗，支持关键词和公网 URL。复用用户联网开关及搜索凭据，选择结果后才写入项目链接；上传按钮直接选择文件。搜索不新建聊天或执行任务。

## 与智能体空间的边界

技能保存在所属项目，默认未启用。启用的技能在新 Run 创建时捕获为内容寻址快照，沿既有运行时技能装载链路使用；后续停用、删除不改变已开始的 Run。不会创建或修改智能体草稿、模型配置、已发布版本、权限或个人技能库。跨用户、跨项目的任务来源校验失败返回 404。

项目技能内容上限 128 KiB、20 个；名称冲突及平台技能与项目技能合计启用数量统一校验。保存复用已有技能文件路径、凭据检查。项目更新使用更新时间比较和数据库行锁，避免并发覆盖。

## 存储与部署

项目技能存于现有项目 JSON 载荷，不新增或回退数据库迁移。174 的基线是 2026-10-27 记忆功能 API 及 2026-10-29 r3 Web。发布产物将本批差异三方合并到该基线，保留记忆功能。

旧 API 不认识非空 localSkills 字段。已经保存项目技能后，回退界面应保留本版兼容 API；如必须回退旧 API，应先备份并迁移项目技能字段，不可直接丢弃。正常发布无数据库结构变更。

## 验证

后端覆盖：产物保存幂等、跨任务文件继承、技能草稿/启用/停用与 Run 快照、智能体版本不变、来源及用户隔离、凭据拒绝、启用技能重名拒绝、搜索使用当前用户配置且不创建聊天。

界面覆盖：独立搜索与选择保存、关闭取消搜索、生成后可审阅编辑且不自动保存、仅保存草稿、启用失败后重试不重复创建。
