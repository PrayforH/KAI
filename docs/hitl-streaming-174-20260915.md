## 行为变化

### Human-in-the-loop

- 试跑从 `approval.requested` 事件即时生成统一审批卡片，展示工具、操作与风险；提交期间禁用按钮，错误可见并可重试。
- 批准、拒绝、过期和取消事件同步更新卡片、活动记录和运行状态；过期按钮不能继续提交。
- 常规任务中的审批卡片按 approval ID 重建，避免上一条审批的本地状态污染下一条。
- 过期审批在 API 与 Worker 进程中具有一致结果：审批过期、运行拒绝；不再根据本进程是否持有 waiter 决定是否恢复。
- 已结束或正在取消的任务不能被迟到的审批恢复。等待者会随终态释放。
- 保留现有拒绝语义：拒绝该审批会终止当前运行。

### 流式构建与效果验证

- 创建草稿使用 SSE 推送实际编译阶段和最终保存结果。草稿初建仍是现有任务编译流程。
- 构建/修改对话向模型发送 `stream: true`，支持 OpenAI 与 Anthropic 兼容接口，逐步展示回复。
- 只展示模型回复字符串；修改内容仍须完整解析、权限和版本检查后形成确认预览。半截 JSON、超长或中断输出不会应用配置。
- 流式连接有心跳、有限队列和断开取消；旧 JSON 请求方式保持兼容。
- 试跑输出以事件流为主，断线后按 sequence 自动续接，并同步最终结果、审批、执行摘要和文件。每个增量不再重置轮询计时器。
- 批量评测新增 `/v1/studio/eval-runs/{id}/events`，推送任务进度和已完成用例结果。后端每 0.5 秒检查耐久状态变化，终态关闭流；前端自动续接。
- 共享 SSE 解析器支持 CRLF、跨字节 UTF-8 分片，并在退出时释放 reader。
