# 构建进度与效果测试会话修复

## 问题与修改

构建助手在发送任何消息时将 `readingMaterials` 设为 true，一直持续到模型完成生成；输入框内因此重复显示“正在读取参考材料并处理要求”。现在仅在真正读取附件时显示该状态，并放在对话消息区，进入模型阶段后立即结束附件状态，输入框只保留输入与附件控件。

效果测试原有 API 支持多轮续聊，但“新对话”将当前轮移到历史后仍显示全部历史，没有清空输入，也没有明确当前对话边界。现在：

- 新对话立即显示空消息区，清空未发送输入、附件及旧回答反馈选择。
- 当前消息区按会话分组，显示轮数及继续追问提示。
- 可以通过“切换测试对话”回看历史并继续发送，续聊关联所选对话的最后一轮。
- 配置 revision 改变时继续沿用原保护：下一轮开启新会话。
- 上传或发送期间禁用会话切换，避免附件或异步结果串到另一个会话。

历史对话选择保存在当前构建工作台的内存状态中；本次未增加刷新页面后的历史恢复接口。
