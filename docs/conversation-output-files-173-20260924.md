# 173 对话输出与文件整理

## 变更

- 修复单个 `TEXT_MESSAGE_END` 提前终结实时正文的问题。正文展示由整轮运行的结束/失败事件收尾；移交处理过程的文本不会重新落入原生正文槽位。
- `ACTIVITY_SNAPSHOT.replace` 传递到过程存储，服务端压缩后的完整快照替换旧片段，避免按 ID 合并留下重复片段。`develop` 的历史恢复替换修复已经在当前分支，本次补齐流式路径。
- 用户手动展开/收起处理过程的选择保留到运行结束和历史重新挂载。未手动操作时仍按运行状态采用默认展开规则。
- 产出入口从复制、点赞操作栏独立出来，始终可见；只统计最终产物，没有最终产物时不显示入口。修正独立入口的纵向 flex basis，避免高度拉伸覆盖下一轮内容。
- 工作区文件采用统一分组：最终产出、输入文件、中间文件、技能资源、智能体配置。仅展示有文件的组，最终产出默认展开，其余默认折叠。组内按已有目录继续折叠，文件名按数字自然排序，搜索可穿透折叠目录。
- 根据既有路径识别 `pdf_pages`、`images_cv*`、`rendered`、`ocr`、`intermediate` 等中间产物；普通图表图片不会仅因图片类型而被归为中间文件。分组是视图行为，没有移动、删除或重写文件。未遵循这些目录命名的文件仍按原目录分组；不声称已经有模型语义分类。
- 主对话与 Builder 使用同一分组函数。输入文件分类只适用于实际传入文件列表的输入路径，本次没有新增主对话输入文件查询接口。
