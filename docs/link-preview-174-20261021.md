## 实现

保留 150ms 的打开、复制工具条，约 200ms 发起元数据请求，约 700ms 切换站点卡片。标题与摘要到达后显示，失败保留可用的打开、复制入口。复制图标在卡片悬停或键盘操作时显示。离开、Escape、滚动、切换链接时清理请求和状态；延迟响应不会污染下一链接。

卡片通过 Portal 渲染，优先置于链接下方，底部空间不足时翻到上方；ResizeObserver 在异步内容展开时重算位置，限制在视口内，不挤动正文。沿用深浅色变量与键盘导航，减少动画偏好关闭入场动效。

Web 新增需验证登录的 `/api/link-preview`。仅抓公开 HTTP(S) HTML，DNS 全量校验后将连接固定到已检查 IP，同时保留 Host/TLS SNI；重定向逐跳校验，禁止凭据、私网地址及非标准端口。无登录 Cookie、认证头或客户端凭据转发。5 秒总时限、最多 3 次重定向、512KiB 页面预算、8 并发、256 项/30 秒缓存与在途合并。只提取并转义为文本，未渲染目标 HTML 或加载远端图片。复用现有 `HARNESS_WEB_TOOLS_PROXY` 时，以已校验的目标 IP 建立 CONNECT 隧道，TLS 仍校验原始站点，代理不会重新解析目标域名；未配置代理时直接固定连接。无需新增依赖或修改 API/Worker。
