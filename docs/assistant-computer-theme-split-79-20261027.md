## 交付内容

- 左侧保留当前会话、输入框和通道状态，右侧是真实 noVNC 电脑。分隔线支持拖动和方向键调整，电脑支持收起、重连、全屏；按本人账号保存当前浏览器的展开偏好。
- 原生欢迎桌面参考粉紫渐变、浅色圆角欢迎面板、时间和底部 Dock。三个主题：粉紫、浅色、深色；四种渐变壁纸：紫罗兰、晴空、青苔、暮色。
- “外观”支持从电脑内选择 PNG、JPEG、WebP 自定义壁纸，限制文件大小和像素数，转为私有 PNG 保存；取消选择不改变正在使用的壁纸。首版没有增加从本机直传壁纸的 Web 接口。
- 欢迎页只展示实际安装的浏览器、终端、文件管理器和文本编辑器。使用固定程序及参数启动 Chromium、xterm、Thunar、Mousepad；不运行来自设置或网页的任意命令。
- Dock 作为真实窗口管理器 Dock，预留底部工作区，最大化应用不会覆盖或被它遮挡。新打开的终端、GTK 应用跟随所选配色；已有应用可能需要重新打开才能应用内容区域的 GTK 配色。

桌面由同一私有 X 会话中的小型 Tk/Pillow 程序提供，不增加本地 HTTP 服务、root 启动接口或公开端口。它是原生欢迎桌面，不是浏览器中的应用模拟界面。

## 保留现有数据

原地更新本人预览 VM 的组件，没有替换 root disk、SSH 身份、work volume 或 Chromium profile。主题与壁纸写到桌面用户的 `~/.config/kai-desktop/`，原子保存、文件权限 0600；未知配置字段保留。Openbox 只更新主题项，保留键盘绑定等内容，并保存第一次修改前的原配置备份。

79 的 Debian 默认下载源连接超时；更新时保留原源文件备份，改用可达的 HTTPS Debian 镜像，继续验证 Debian 签名。原账户、飞书/微信绑定、数据库和聊天记录没有迁移或清空。生产模型执行 Computer 及其原工作盘未变更。
