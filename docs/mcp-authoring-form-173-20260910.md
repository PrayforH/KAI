## 1. 问题

用户反馈「MCP 配置表单左右有空白区域，深色浅色都需要调整」。实测（1920×1080，注册 MCP 表单）确认了三处：

| 现象 | 实测 |
| --- | --- |
| 单字段行右侧整片空列 | 表单为固定两列网格，「显示名称」「执行位置」各自独占一列，右侧半列空白；「03 鉴权」整段只有一个下拉时，一行 1526px 里空出约 1155px |
| 浅色下分区没有层次 | 浅色时 `--paper`（页面）= `--panel`（分区卡片）= `--field`（输入框）= `#ffffff`，三层同为纯白，编号分区只剩一条 1px 描边；深色则是 `#111` / `#242424` / `#1d1d1d` 三档 |
| 深色下同样存在 | 单字段行的空列与浅色一致，与配色无关 |

## 2. 改法

只改 `web/harness-console/src/components/agent-studio/mcp-catalog-control-plane.module.css`：

1. **字段网格 2 列 → 3 列**。分区里的短字段（引用标识 / MCP 服务名 / 显示名称；风险级别 / 网络范围 / 执行位置）本来就是三个一组，三列让整行铺满卡片，不再出现空列。响应式回退：`≤1320px` 两列、`≤680px` 单列（沿用原有移动端规则）。
2. **浅色分区层次**。浅色下把「编写页」底色改为 `#f7f7f8`，分区卡片保持纯白并加 `#e4e4e7` 描边与极轻投影，形成与深色对应的「底 + 卡片」关系。`editorBackdrop` 与 `.editor` 共用同一底色，否则编辑器自身的边界会在背景上留下一条色带。
3. **表单页保持与列表同一栏宽**。中途曾把编写页放宽到 `min(1800px, 100%)` 以消除宽屏留白，按用户「更窄一些」的要求改回 `min(1160px, 100%)` —— 与 `已安装` 列表、技能页 `.content` 同栏宽，打开表单不再改变页面measure。

深色配色未改动。

## 3. 验证

173 实测（真实数据），深浅两色 × 两种窗口宽度：

| 项 | 1440×900 | 1920×1080 |
| --- | --- | --- |
| 编写页宽度 | 1160px（左右各 8px） | 1160px（左右各 248px，与列表同栏） |
| 字段网格 | 3 列（每列 335px） | 3 列（每列 335px） |
| 分区行内余量 | 17px（即卡片内边距） | 17px |
| 浅色底色 / 卡片 / 输入框 | `#f7f7f8` / `#ffffff` / `#ffffff` | 同左 |
| 深色底色 / 卡片 / 输入框 | `#111111` / `#242424` / `#1d1d1d` | 同左 |

- 「01 基本信息」「02 连接配置」「04 运行边界」「05 连接测试与工具」的分区行内余量均为卡片内边距（17px），即行已铺满。
- 「03 鉴权」在“无需鉴权”状态下只有一个下拉，仍占一列；该段在切换到需要凭据的鉴权方式后会补齐其余字段。
- 断点回退实测：1280 / 1100 / 900 → 2 列；≤680 → 1 列。
- 深浅两色截图逐段核对，仅配色不同。

## 5. 部署与回退

- 仅前端样式变更；api 镜像按同一 `src/harness` 重建，使 `HARNESS_HARBOR_IMAGE_TAG` 与两个镜像保持一致（避免出现「env 指向的镜像不存在」的隐患）。
- 回退：`.env.production.bak-mcp-form-narrow-20260910-<时刻>`（路径记录在 `/data/agent-studio-builds/mcp-form-narrow-20260910/env-backup-name.txt`）；上一版镜像 tag 为 `mcp-form-layout-20260910`。
- **本记录发布的 `mcp-form-layout-20260910` 与 `mcp-form-narrow-20260910` 两个 web 镜像因收窄构建范围，曾覆盖掉线上在途的知识库 Wiki/分块配置表单**，已由 `kb-wiki-form-20260914` 从全量工作区重建恢复，详见[事故记录](incident-173-scoped-web-build-dropped-wiki-config-20260914.md)。后续 web 镜像一律从全量工作区构建。

## 6. 已知边界

- 「03 鉴权」在单字段状态下的右侧留白属于表单常态（单字段行不拉伸），若期望其铺满需按鉴权方式条件渲染出同排字段。
- 编写页在 ≥1664px 的窗口下两侧会重新出现留白，这是与列表同栏宽的直接结果；若希望宽屏铺满可只放宽 `.editorBackdrop .editor` 的 `min()` 上界。
