## 改动

1. 后端首段文字仍立即发出。后续小段文字增加 50 ms 刷新期限，保留原有 64 字及标点合并规则；上游暂时不发新消息时，也能发出已收到的文字。
2. SDK 读取与清理始终在同一个生产者任务中执行，避免 tracing ContextVar 与 SDK cancellation scope 跨任务问题；单元素队列保留背压，超时只取消队列读取。结束、出错、取消均释放生成器并处理已收到的尾部。
3. 短回复不再一直等到 160 字。首次正文到达后最多等待约 180 ms，再进入回复区域；快速出现的工具前言仍归到执行进度，切换消息/任务时取消旧计时器。
4. 使用现有 assistant-ui 平滑组件进行自适应文字展开，每约 32 ms 提交一次显示更新；长块加快追赶，收到完成状态后进一步加速收尾。历史消息直接显示，遵循系统减少动态效果设置。
5. 使用固定版本 `remend@1.1.0` 在平滑展开之后补全显示中的 Markdown 语法，避免未闭合粗体和链接反复变形；未完成链接不允许点击。显示补全不写入消息存档，完成后回到原始正文。
6. Markdown 解析交给 React 延后调度，降低长回复解析对输入和滚动的阻塞。表格滚动、代码、引用和 Wiki 渲染继续使用原组件。
