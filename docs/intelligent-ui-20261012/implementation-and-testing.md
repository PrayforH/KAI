## HTML 链路

模型先发布本轮实际的 HTML 产物，再在 `harness-ui` 中声明 `kind=html`、`data.artifact_id`。后端只接受同租户、同 Run、同 Session 的 `artifact.ready` 权威事件，必须是已就绪的 text/html，大小 1–262144 字节。模型不能声明正文、URL、路径或哈希。真实模型三次都把 artifact_id 写在顶层，首次因此未内联；已兼容这一种确证简写，并增加标准 HTML JSON 示例。包含双重引用或其他未知字段的输出仍拒绝，投影仍需权威产物匹配。规则版本升到 presentation-policy/6。投影记录服务端哈希与产物事件序号；读取时再次验证归属、版本、大小和实际内容 SHA-256。

聊天使用 sandbox=allow-scripts 的 iframe，不授予同源身份。受鉴权保护的 HTML 读取端点返回 CSP；Next.js 代理保留这些响应头。内联脚本和样式可执行；联网 API、外部脚本、嵌套页面与表单提交受限制；公共 HTTPS 图片可展示，仍需查验来源与实际可见性。

状态通道只接受来自本 iframe 的 opaque origin 消息以及本次挂载的随机 token。先恢复个人视图，再创建 iframe；父端先安装消息监听器，页面初始化控件后握手。只保存 12 KB 以内 JSON 对象，使用现有个人视图的版本校验、350 ms 防抖和 CAS；没有工具调用桥。未采用状态协议的 HTML 仍可在当前页面操作，但重新打开从初值开始。浏览器能否执行复制、游戏键盘及实际恢复，必须另行点击验收。
