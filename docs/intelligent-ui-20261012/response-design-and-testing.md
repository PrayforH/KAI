# Response 设计对齐

按用户补充的范围，统一追问与 response 的样式、图标、文字排版、动效和交互。来源为本机 Codex 26.1007.30912 / build 20156 的 UI bundle；路径、哈希、图标名称见 codex-response-reference.json。

## 样式与图标

复用客户端 Markdown 的比例规则：1.625 行距，字号四分之一作为间距单位，标题比例 1.5 / 1.25 / 1.125，表格用横向分隔线、等宽数字和横向滚动，行内代码 0.92em 与 6px 圆角。以项目 14px 正文字号适配；客户端桌面默认回退为13px且可配置，不假设用户的客户端设置值。代码字体、深浅主题颜色继续使用项目与系统已有字体和 token，没有引入字体下载。

复制、勾选、赞、踩、展开箭头、铅笔和外链箭头采用本机客户端对应16px单色SVG路径，集中在 CodexResponseIcon。追问页的标题、导航、已选标记和补充输入也使用这组图标；回答操作栏、代码复制和展开控件统一大小与反馈。来源链接使用轻量虚线下划线，保留域名与打开目的地信息。

样式集中在 response-design.css，限定回答区域，避免改变活动日志、文件预览和侧栏的密度；明确覆盖旧版浅色主题的字号/行距，深浅主题使用相同排版比例。

## 动效与交互

客户端通过稳定的 Markdown token key 做新增文字淡入。本项目保留现有 Markdown 与实时响应链路：新增段落、列表项、表格行渐显，文字在已有节点内继续增长时不重新播放动画，也没有额外打字机队列。用户展开已完成回答时，只渐显新增内容。新父节点与其子节点不重复播放；历史初次展示立即可读，选择阅读中的文字时跳过渐显，减少动态效果设置会取消正在播放的动画。

操作栏保持悬停/键盘焦点反馈，触屏保持可见；展开/收起按钮提供 aria-expanded 与旋转箭头，原长列表/表格的内容保留和恢复路径延续。代码复制复用现有支持 HTTPS 与私网 HTTP 的工具；只有复制返回成功才显示“已复制”，拒绝或不支持时显示“复制失败”，避免并发复制，并在组件卸载时清理恢复计时。消息复制与代码复制共享降级逻辑，消息仍先做原有换行规范化，代码保留原始空格。

未实现客户端整个 token 渲染器，也不复制其内部依赖；当前渐显单位是段落/行。实际视觉、选择体验、滚动行为及系统复制权限仍需浏览器验收。
