# 79 我的助理切换与空闲刷新优化

2026-10-26，Asia/Shanghai。代码 `d651afe9`。访问：[我的助理](https://172.20.105.79:3543/assistant)。

## 原因与修改

助理每三秒读取外部通道的历史。AG-UI 转换器为缺少日期的消息补充当前 `createdAt`，原来的整个仓库 JSON 比较因此每次都不同，导致没有新消息也重置整段对话。现在比较消息内容、状态与元数据，排除转换器生成的日期；实际新增或变化的消息仍立即导入，终止恢复和已加载的早期消息仍保留。相同的执行活动不再重复通知全局订阅者。

运行时初次加载历史和外部同步首次检查原来会分开请求，因为同步先删除了正在进行的共享请求。现在同步只使完成的最新页缓存失效，复用正在进行的读取。工作区中助理入口预加载路由，鼠标进入或键盘聚焦时预取历史。

没有本地智能体绑定时，先使用服务端当前账号有权读取的线程摘要打开历史，完整智能体目录继续在后台校验。原来冷启动等待目录、模型列表与线程摘要全部完成。服务端初测历史约 0.30 秒，完整智能体目录约 1.62 秒；两者不再串在聊天首次显示的关键路径上。没有修改服务端的账号鉴权或发送授权。
