# 173 思考展示稳定性

代码版本 `5b197683`，分支 `auto/agent-evolution`。

## 问题与调整

原思考行截取末尾 600 字符，并在每次更新后将 `scrollLeft` 设置为 `scrollWidth`。高频增量使预览不断横移，旧行即便不再处于活动状态也会在文本更新时滚动。模型未提供或复用 `item_id` 时，不同工具回合的思考还会合并进旧行。

- 移除思考预览的自动滚动及扫光效果。收起状态下，当前思考稳定显示“思考 · 进行中”；结束后只显示静止的内容开头，单行省略。
- 完整内容按需展开，保留已有 250px 高度上限和独立滚动区域。直接渲染文本，避免对每个增量重新解析长 Markdown；不自动更改阅读位置，也不积压打字动画。
- 根据工具、审批、子任务或正文事件划分思考段，防止复用标识将后续思考追加到旧步骤。正文开始和运行结束后停止活动状态。
- 复用现有文字、颜色和间距，增加键盘焦点提示；正常工具行仍使用原有执行状态显示。
