## 修复内容

| 问题 | 最终行为 |
| --- | --- |
| 首页同次挂载加载两遍目录 | 首次绑定负责初始加载；另一个 effect 只监听焦点/可见性。隐藏内部智能体的偏好变化也正确更新列表。 |
| 15 秒身份轮询 | 移除固定轮询；保留失效广播、真实请求 401、窗口焦点和可见性校验。身份读取短期共享，5xx/网络错误不当成会话被替换。 |
| 智能体页面预取四个隐藏面板 | 仅进入相应完整配置面板时读取；列表不再加载第一个草稿正文，版本历史仅在打开时读取。 |
| 列表无缓存、多处重复请求 | capabilities、knowledge/bases、drafts、技能目录共享 10 秒内存缓存和并发请求。首页模型目录使用同一 capabilities 缓存。 |
| 缓存正确性 | 普通写入、流式写入、文件导入、技能安装、草稿删除及身份广播使缓存失效；失效前的请求不能回填新缓存。失败不缓存，快照最多 128 项。 |
| 技能目录 2+N | 新增 `/v1/studio/skills/agents`，按用户/空间权限一次返回技能目录字段；不返回草稿 System Prompt 和附件内容。个人目录变为两次请求。 |
| Wiki 旧引用 1+N | 已知知识库仍直接读取；缺少归属的旧引用调用 `/v1/studio/knowledge/wiki/resolve`，浏览器只发一次请求。后端最多四路并发；同名冲突拒绝猜测，真实上游故障不会伪装成唯一匹配。引擎内部仍最多查询 N 个可见库。 |
| 知识库文档双轮询 | 单个完成后再调度的计时器，初次载入的解析中文档也会刷新；后台/其他面板暂停，慢请求不重叠，卸载/换库丢弃迟到结果。删除等待两分钟后停止并提示，连续失败退避后停止，可手动刷新。 |
| 知识库计数的额外放大 | 先过滤当前用户可见知识库，再最多四路查询计数；Wiki 归属解析不额外刷新文档数。 |
| 编辑器代码阻塞列表加载 | 构建助手和代码编辑器按需下载；首次打开后保留助手组件，避免回到列表再进入丢失该组件状态。知识图谱按需加载。 |

## 174 测量结果

### 技能目录

同一个独立验收身份，8 个草稿，每个草稿包含一个技能及 64 KB 文本附件。旧链路采用原有的四路草稿并发，新链路采用批量接口；每组连续测量三次，均为服务器本机 HTTP 请求。

| 指标 | 旧链路 | 新链路 | 减少 |
| --- | ---: | ---: | ---: |
| 请求数 | 10 | 2 | 80% |
| JSON 响应总字节 | 758,756 | 209,004 | 72.5% |
| 总耗时中位数 | 91.8 ms | 26.9 ms | 70.7% |

原始数据：[benchmark](results/performance-174-benchmark-20260915.json)。该测量不包含用户网络、浏览器排队和渲染，不等同于页面切换时间。

### 智能体列表的首屏脚本

比较旧/新生产构建的 `/studio/agents` HTML 实际引用的脚本，按文件内容计数；gzip 数值是本地压缩估算，不是抓包结果。

| 指标 | 旧版 | 新版 |
| --- | ---: | ---: |
| 首屏脚本数 | 19 | 16 |
| 未压缩 JS | 2,128,399 B | 1,211,487 B |
| gzip 估算 | 635,771 B | 342,761 B |

未压缩体积减少 43.1%，gzip 估算减少 46.1%。原始数据：[initial scripts](results/performance-174-initial-scripts-20260915.json)。
