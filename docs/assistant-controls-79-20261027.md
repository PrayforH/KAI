## 用法

| 私聊内容 | 行为 |
| --- | --- |
| `进度` / `/status` | 查询本人共享助理线程的实际执行状态；有活动任务时优先报告活动任务 |
| `停止当前任务` / `/stop` | 请求停止捕获的当前 Run；Worker 未退出时明确显示正在等待停止 |
| `/补充 新要求` / `/steer new instructions` | 提交到原 Run 的 steering inbox；不将提交、发送到 SDK 和执行器确认接收混为一谈 |
| `助理帮助` / `/help` | 返回简短说明 |

普通对话和附件继续沿用原会话。带附件的 `/stop` 文字仍作为内容处理，不执行停止。飞书原有“停止 标题”“补充 标题”等事项命令保留。控制命令不新增模型聊天轮次，执行状态及被接收的补充沿用原 Run / 事件；不增加设置页。

目标先持久化，变更在下一次处理执行。重启或投递失败后继续使用原目标，避免取消新出现的任务。绑定、账号可用性、租户及共享线程的归属在处理和投递前重新检查。微信新增独立的控制处理队列，普通消息与控制消息不会互相领取正在投递的行。
