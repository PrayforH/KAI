# 173 WeKnora 知识问答审查与修复

日期：2026-09-09。基线：`feature/weknora-knowledge-base` / `43469f4`（文档提交 `dbcf095`）。

## 实际实现链路

1. `harness-console` 编辑器保存会话选择的知识库和 `rag/wiki` 模式，使用 `forwardedProps.knowledgeReferences`、`knowledgeMode` 传给 AG-UI。
2. AG-UI 按当前用户与会话团队解析可访问的知识库绑定，作为 `knowledge_binding_override` 写入当前运行；空选择沿用智能体默认绑定。
3. Claude SDK 运行时根据模式注入知识工具与回答约束。进程内 SDK MCP 与远端 HTTP MCP 使用同一个知识服务。
4. RAG 调用 `query_knowledge_sources`：legacy 来源使用快照检索，WeKnora 来源调用 174 的 `hybrid-search`；返回切片正文与来源。
5. Wiki 调用 `search_wiki_pages`：检查绑定与权限后调用 WeKnora Wiki 搜索，返回知识页面。Wiki 开关选择的是回答依据，不是启用/禁用知识库 Wiki 构建。
6. 模型生成答案；工具结果中的切片引用通过 AG-UI activity 持久化，前端按消息展示来源。Wiki 是经过模型整理的知识页面，和原始文档切片的证据粒度不同。

## 语义与保留边界

- 清除会话选择 = 恢复智能体默认知识库，不是完全禁用知识检索；选择器文案已明确。
- Wiki 关闭 = 文档检索；Wiki 开启 = 已构建的知识页面问答。对于混合选择中不支持 Wiki 的库，不会产生 Wiki 命中。
- 新回答支持明确的来源链接；旧答案中模型自行写的 `[1]` 仍是旧文本，不能无依据推断它属于哪次检索。来源列表仍可查看。
- 来源列表表示检索候选，并不宣称模型使用了所有命中；相关分数也不是答案正确概率。
- Codex 知识 MCP 接入未新增，本次消除显式选择知识问答时的静默失效。
- legacy/WeKnora 混合检索的分数校准、Wiki 页面底层原始文档证据追踪、模型回答质量评测集，仍可作为后续独立改进。
