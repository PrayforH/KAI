## 已实现的功能

1. 智能体独立侧栏：概览、Playground、会话；质量与运营展开后可进入原有评测、轨迹、审批、触发器等能力。
2. 概览以近期试跑、待处理事项、配置摘要为主。点击会话可回到实际历史记录。
3. Build 为配置列和对话列；Chat 隐藏配置列、展示会话列表。配置通过对应抽屉修改，不再同时铺开全部表单。
4. Model & harness、AGENTS.md、Tools、Skills、知识库、子智能体、Advanced 和触发器有明确入口。保留 skill-creator、DeepAgents 代码/差异视图、项目导出和发布。
5. 模板目录支持分类、搜索、详情和创建，提供 8 个本地任务模板。模板真正写入草稿的指令、任务合同和示例，不自动发布或配置外部凭据。
6. 试跑直接复用主窗口 AgentThread：同一个输入框、附件上传与粘贴、Markdown、执行过程、文件展示、复制和反馈组件。外部运行时适配器只连接 Studio Try Run API，没有另一套独立试跑输入框或回答气泡。
7. ConversationScope 隔离试跑运行、审批、流式文本等状态；主对话在没有该上下文时保持原有行为。试跑使用当前草稿的模型和知识库，相关配置从草稿抽屉修改。
8. 失败发送恢复输入与附件；Build/Chat 切换保留未发送内容；新会话清空当前输入；同一修订续聊、修改配置后新开试跑会话。
9. 后端恢复当前账号的预览历史，校验租户、用户、草稿和 preview 环境。列表限制为最近 100 个会话、最多 200 次运行，暂不提供无限历史分页。

## 人工验收路径

1. 打开智能体目录，新建智能体，筛选并查看模板详情，创建后确认名称、AGENTS.md、示例输入正确。
2. 在 Build 修改 AGENTS.md 或模型配置，保存后检查修订更新；确认只打开对应配置抽屉，Escape 可以关闭。
3. 在试跑输入多行文字、粘贴附件，检查其交互和主任务对话一致。发送后检查 Markdown、执行过程、回答操作和文件入口。
4. 输入未发送内容，切换 Build / Chat，确认文字仍在。创建新会话、刷新页面、选择原会话，确认历史回答恢复；同一草稿修订追问保持会话。
5. 修改配置后再次试跑，确认使用新修订并开始新会话。运行中停止；需要审批时检查批准/拒绝及批量审批。
6. 打开 DeepAgents 代码、对话修改后的差异视图，导出项目并检查压缩包内容；Skills 入口应携带当前草稿上下文。
7. 从概览返回历史会话，检查评测、轨迹、触发器等旧功能仍可进入。不要在验收时创建无意义的定时任务。
