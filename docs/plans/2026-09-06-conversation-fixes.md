## 文件隔离排查

174 只读查询显示：没有一个 session 被多个 thread 绑定，也没有文件哈希跨 session 重复的记录。修正了已确认的界面风险：旧任务文件在新的 effect 执行前仍可留在组件状态。新增服务器任务过滤，避免全量下载再筛选；全局「我的文件」保留查看本人所有任务文件的功能。

回归场景包括：同一智能体两个任务、相同文件名、列表 limit=1、跨任务下载、未授权用户、任务切换期间异步请求未完成。全部通过。

## 验证边界

输入法测试使用真实 React 19 组件与 DOM 组合输入事件覆盖候选文字及 Enter；页面测试使用隔离模拟 Runtime，不调用收费模型。技能测试只检查选择与跳转，不创建正式技能或改动已有智能体版本。
