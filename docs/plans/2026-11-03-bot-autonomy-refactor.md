# Bot 自主执行与平台控制面分离

基线c84b9680，独立工作树kai-weather-fix，分支refactor/kai-bot-runtime-20261103。用户授权实现、79真实验收与飞书同步。

平台保留：Bot持久身份、会话历史与领域记忆；现有所有权/工具权限/状态校验；原消息来源、附件、幂等投递、执行状态与结果回传。保留用户自己定义的职责和业务规则。

平台删除：每轮强制路由分类、direct_kind分桶及理由验证、按天气词表阻止结束、业务工具调用前后固定步骤、创建后强制首次派工、按故障不断叠加的角色/开场/结束提示。普通任务和项目保留原交互；Bot使用一份简短身份与能力约定。

创建与发送为独立工具，模型可自行处理、委派、澄清或继续工作；每条消息有独立请求键，平台只检查权限、收件人、来源和输入完整性，不限制某领域、任务步骤或本轮工具调用顺序。复用现有Profile、AG-UI、Run、EventService和SSE，不新增任务引擎或数据表。

验收：无强制分类即可调用授权工具；原权限拒绝仍生效；创建不自动运行/设周期；按需多次消息而非一轮唯一决定；并发重试/恢复/跨账号/停止/附件完整性；实时来源和历史保留、普通任务/项目隔离。79空闲时仅更新必要服务，保留原数据与VM，真实页面验证后同步飞书当前原则与旧方案废止项。

用户追加：主会话是统一交互入口；子Bot的补充、确认、操作授权与凭证收集投影到原消息位置。普通回答通过带原Run关联的消息继续原子会话，并将后续结果回到同一来源；过期问题、跨会话和并发重复回答由服务端拒绝。真实工具授权继续用原Approval ID和权限校验，不把普通确认当授权。敏感字段使用已有加密凭证入口，消息只携带已保存的引用说明；未实现的工具消费或浏览器自动填入不能声称已支持。已通过本地Grok Bot原生客户端查看现有确认卡与来源行；凭证外观沿用用户Vault截图，未读取真实Grok Vault。

完成情况：主实现38226454，续轮模型继承864b25e9，空结果状态6b9c8354，Bot中断状态行45e38107，主问题与通知隔离e31b784d，过期问题卡随投递更新95dcce86。已部署79并完成主实页问答往返、合成凭证卡、只创建联系人和可恢复归档验收；报告见docs/results/2026-11-03-bot-autonomy-79.md。飞书11.13当前方案和最终证据已同步至版本102。实际浏览器凭证消费、生产权限变更审批实测、既有队列繁忙导致的排队超时及前端旧失败不冒称完成。
