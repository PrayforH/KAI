# 智能体工作台第一阶段精简

## 目标与范围

将 173 验证环境的智能体页面收敛为一个桌面工作台。智能体列表直接进入工作台，不再经过概览，不区分“我的 / 团队共享”视图；访问权限仍由服务端控制。质量、评测、改进、审批、定时任务等运营入口暂时收起，保留底层能力和数据。

## 交互

- 一个主对话和一个输入框，统一提出配置修改、上传材料及执行试跑。复用主对话消息、附件、发送与停止组件。
- 删除底部“已从控制面加载”状态栏；保存状态保留在顶部，操作反馈使用可关闭提示。
- 输入框只显示“＋”上传图标及发送 / 停止按钮，上传用途通过可访问名称和悬停提示表达。
- 顶部保留配置、版本历史、代码和更多操作。配置可折叠；发布收进更多菜单。
- 修改建议直接显示在对话中；用户应用后仍留在对话，后续试跑使用保存后的修订。
- 版本历史保持独立侧滑层：左侧选择草稿/发布版本，右侧展示本次改动的逐行差异。文件面板与对话并排，复用主对话文件组件，展示 AGENTS.md、Skills 附属文件及对话产物；按本次打开时的草稿基线标记已修改、已新增、已删除。DeepAgents 导出项目不混入普通内部文件列表。
- 保留 skill-creator、DeepAgents 代码视图、代码差异与导出。

## 验证

前端全套测试 122 个文件通过，773 项通过、1 项跳过；TypeScript 检查和生产构建通过。另以真实 173 API 验证附件上传、试跑、会话恢复，以及展开配置 / 版本历史时保留输入。

浏览器验收证据见 docs/validation/2026-09-21-agent-workspace-simplification.json。

## 实现边界

这是入口和工作台交互精简，不删除质量与运营服务；已有明确 URL 仍可访问旧功能。版本历史中的“最近改动”明确限定为本次打开期间，尚未替代持久化的完整草稿修订审计。历史发布版本接口目前仅提供元数据，没有文件快照，因此这类版本明确显示无法逐行比较，仍保留设为当前版本的能力。试跑会话可从服务端恢复；构建助手对话暂不持久化。隐藏目录分组不改变服务端权限。

部署只替换 173 隔离环境（3302）的 web 服务，API / Worker 保持当前版本，原环境 3301 / 8800 不变。
