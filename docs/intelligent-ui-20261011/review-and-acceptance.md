## 1. Review 后的实现

**HTML 路径边界。** 本轮 A/B 的聊天内呈现是受限数据协议加固定组件，不是模型生成完整 HTML。项目已有模型生成 HTML 文件后在产物栏预览的能力，使用允许脚本、但不开放同源权限的沙箱 iframe；这允许页面内交互，并不直接赋予 HTML 调用平台工具的权限。自动选择自由 HTML、直接展开及与平台动作衔接的完整链路属于阶段 D，尚未在本轮完成。

模型决定适合的呈现形式，后台进行协议校验与发布，客户端按照 renderer 版本渲染。通用表格、比较、图表、流程图、时间线、指标和表单可在聊天里展示；下载文件、独立页面或超出组件能力的互动才进入 HTML 产物。Memory Bank 可以为后续阶段提供偏好，本次 A/B 不把长期记忆当作界面协议、授权或执行状态的权威。

终态 Run 发布不可变快照，包含可信 Run/Session/Agent 身份、revision、来源与内容哈希。实时消息、重连和历史读取同一份发布记录，既有已发布内容不因之后的投影策略升级而变化。`history.snapshot` 使用 v4；模型明确要求的组件优先于工具结果的自动表格投影，每轮最多两个块。客户端只移除服务端确实接受的代码片段，拒绝的片段保留为原始文本。

动作端点只接收服务端分配的 presentation/action ID、expected_revision、幂等键和按字段 key 传输的表单值。服务器重新检查用户、任务和团队访问权限，验证字段，并将按钮意图映射到当前任务的 Run 执行器。read/conversation 收紧为只读工具策略，write 沿用任务已有策略。按钮不能指定新的身份、任意工具入口或覆盖权限。

请求耐久保存后再派发，恢复过程使用租约与 fencing。写动作在同一用户、组件、动作、revision 下只受理一份内容；换浏览器幂等键仍返回同一个请求，不创建第二个 Run。改变已提交写入内容、旧 revision 和冲突的视图保存被拒绝。read 动作完成后可以再次执行。表格排序、图表“查看数据”与未提交表单值按 revision 保存，提交值可从该用户的请求恢复。

动作状态区分受理、排队、运行和终态，202 不显示“业务完成”。完成后加载同一任务的历史，用户能看到按钮产生的自然语言请求和结果。事件 outbox 使用稳定 event ID；修复了持久化后发送失败和并发发送时序号竞争两个问题，使重试复用已存事件的序号并继续发送。

## 3. 页面测试方式

打开 173:3302，登录后新建任务，选择可用模型和正常任务智能体。为避免旧任务上下文继续生成文件，建议从新任务开始。

**图表**：发送“请在当前聊天里展示一张季度利润柱状图：一季度 120、二季度 -30、三季度 80、四季度 160，单位万元。不生成文件或独立页面，不联网。”等待完成后，应看到图表，二季度在零轴下方；点击“查看数据”核对四个数值，再刷新确认数据表仍展开。

**表格**：发送“请在聊天里展示可排序表格：一季度利润 120、二季度 -30、三季度 80、四季度 160，单位万元。不生成文件，不联网。”点击利润列排序，检查数值顺序；点击复制，检查成功提示；刷新确认排序恢复。CSV 下载是本地数据导出。

**表单与按钮**：发送“请在聊天里给我一个项目摘要表单，收集项目名称、预算（数字）和优先级（高/中/低），三个字段必填。填写后点击‘生成项目摘要’，仅根据填写内容返回三句话摘要，不使用工具、不创建文件、不提交任何业务数据。现在只展示表单，等我填写。”缺少必填值时按钮禁用；填写后先刷新验证值保留，再点击按钮。应看到排队/执行状态和新的摘要轮次，刷新后填写内容与结果仍在。

测试按钮时用此类无业务副作用的任务即可，不需要设置专用审批。read 表单可以再次生成；write 表单已经提交后锁定，API 重试仍返回原请求。不同模型会选择不同的组件，普通文本仍是正常输出；未通过校验的未知格式会保留原文，不执行。

## 4. 联网图片：本地 Tavily

用户已说明 MiniMax 当前不支持图片获取，Tavily 在 173/174 不可用。因此服务器提供方配置保持原状；图片检索在本地以项目 `PublicWebClient("tavily")` 发真实请求。

公开查询 `Shanghai museum architecture exterior images` 返回 5 条搜索结果、17 个图片链接，其中 12 个带页面来源。证据为同目录 `tavily-local-evidence.json`。WebSearch 新增可选图片请求和图片描述，保留来源、限制返回量，并过滤明显私网或非法 URL。MiniMax 的图片请求明确返回“不支持”的状态与说明，文本检索仍可使用。

本次证明的是检索返回图片 URL 和来源，未把图片二进制下载、服务器图片联网可用、完整图库组件或每个远端图片链接永久可用计为已验收。需要联网图片的场景请在本地启用 Tavily 测试；173 页面先用给定数据完成 UI 验收。
