# 统一构建入口与附件流程

发布标识：`20260908-003754`。

## 流程决策与修复

管理页保留智能体列表与管理操作，新建和编辑进入同一个构建工作台。管理页不再显示旧右侧抽屉，避免重复的创建/修改/试跑入口。

旧抽屉残留的原因是返回列表只切换了 `viewMode`，但助手仍处于打开状态；失去工作台挂载点后又走到了旧抽屉布局。现在助手只在编辑模式且挂载点就绪时呈现。返回按钮明确回到智能体管理页，未保存配置沿用保存/放弃/继续编辑保护；子智能体的返回父智能体功能另行保留。

创建需求只生成草稿并展示配置，不再自动调用试跑。创建时上传的附件保留到右侧，用户输入实际测试问题后才发送；创建完成提示也不再声称已开始测试。

其他改动：

- 顶部去掉保存按钮，配置内保存保留。发布对齐 MCP 新建按钮的 34px 高度、8px 圆角和主题颜色。
- 运行中停止/发送按钮互斥，取消后恢复发送。
- 右侧附件排列改为左对齐；支持文件选择、图片粘贴和文件拖拽，图片显示缩略图。上传失败可重试，提交或移除后回收预览 URL。初始附件转入右侧后清理交接状态，返回管理页再进入不会把已发送的附件重新回填。
