# 174 「自动化」模块发布（2026-09-19）

本次发布在 174 环境上线一级导航模块「自动化」：定时任务（含 12 个模板、添加/编辑弹窗、
立即执行、暂停/恢复、删除）与运行记录（筛选/搜索/刷新、状态徽标），深浅两套主题全部走
`--codex-*` 语义 token。

## 代码变更（feature/automation → develop）

- `src/harness/automations/`：新领域。`AutomationTask`/`AutomationRunRecord` 模型、
  五字段 cron 求值器（支持 `*/n`、范围、星期别名、时区）、服务层（CRUD、
  `dispatch_due` 原子认领防重发、手动执行、记录状态按 Run 终态推导）。
- 执行链路：到点/手动创建 workload Session + Run（与 AGUI 一致，按任务 owner 的
  最新 published agent 版本钉版本，可用 `HARNESS_AUTOMATION_AGENT_VERSION` 覆盖，
  亦兼容 `HARNESS_AGENT_NAME`/`HARNESS_AGENT_VERSION` 别名），由 worker 队列执行；
  单进程本地部署可注入 inline executor。
- 存储：`automation_tasks`/`automation_records` 两张表，迁移 `0034_automations`。
- 路由：`/v1/studio/automations`（列表/创建/更新/enable/pause/run/删除/next-runs/records），
  经 Next BFF `/api/studio/*` 代理。
- 前端：`/studio/automation` 页面 + `AutomationManager` 组件；左侧导航「自动化」位于
  插件（技能/MCP）之上；模板预填、必填校验红描边、下次执行预览、删除二次确认。
- 测试：后端 19 项单测（cron 求值 + 服务调度），前端 111 个测试文件全绿（含
  `tests/automation-manager.spec.ts`）。

## 已知边界

- 「会议前准备」模板（事件型）在本期退化为单次任务。
- 失败自动重试（1-2 次退避）与结果投递回聊天会话的深链跳转留待下期；
  当前运行记录已含 sessionId/runId，可跳转 run 详情。
- worker 每 1s 轮询 `dispatch_due`（与 triggers 维护循环同频），错过的单次任务会
  迟到补跑；超过有效期（validity.until）的周期任务自动转「已结束」。
