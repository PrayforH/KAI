# 录音后统一转写：Qwen3-ASR-1.7B

## 产品行为

录音时仅显示波形，音频缓存在浏览器内存，不请求 ASR，也不改变原输入框文字。点击对勾后停止并释放麦克风，再上传一段 16 kHz 单声道 PCM WAV，显示“正在转写…”，收到结果后一次性插入原选区。仍需用户手动发送任务。不会默认调用所选聊天模型润色识别结果。

取消保留原文；请求失败显示错误并允许使用同一段音频重试；空识别和不足一秒的录音提示重新录制。取消请求、卸载、权限弹窗晚返回、重复点击以及设备断开均有生命周期保护。录音上限沿用配置，174 为 120 秒。完整音频只存在于组件内存，成功、取消或卸载后释放。输入法组合尚未结束时延后回填，避免丢掉中文输入或识别结果。

## 参考和模型选择

- 本机 `/Applications/ChatGPT.app`，版本 `26.1013.40934`：只查看应用资源中的录音、停止、转写、取消、重试状态和 `/transcribe` 请求结构，未读取用户聊天数据。其代码也有 streaming 分支，不能据此推断所有 Codex 模式内部都统一采用整段上传。
- OpenAI 官方开源代码：[`rust-v0.105.0` 的 voice.rs](https://github.com/openai/codex/blob/a7eda6a29b3ee25549f385197ff109508dc49a90/codex-rs/tui/src/voice.rs)。该历史版本存在完成录音后编码 WAV 并上传转写的流程；不是把历史实现声称为当前最新版。
- [Qwen3-ASR 官方仓库](https://github.com/QwenLM/Qwen3-ASR)、[1.7B 模型卡](https://huggingface.co/Qwen/Qwen3-ASR-1.7B)：支持离线和流式、多语言及中文方言。按用户选择使用现有网关的 `Qwen3-ASR-1.7B` 路由，不重新部署共享模型服务。

“录完再转写”的产品行为与后端模型独立。Qwen3-ASR-1.7B 适合作为本次主模型，但未用真实办公室语料做与 Fun-ASR-Nano 的准确率对比，不宣称全面胜出；转写也不能自动区分同时录入的旁人讲话。

## 本地验证

- 前端语音相关 50 项测试通过，覆盖整段上传、重试、取消、晚响应、权限、时长、选区、手工修改及 IME；TypeScript 无错误。
- 后端语音相关 22 项测试通过，覆盖 21/120 秒录音可用、121 秒拒绝，且旧 VAD 20 秒限制不变；Ruff 与 diff 检查通过。
- 174 容器到现有 Qwen3-ASR-1.7B 网关，两段 macOS Tingting 合成中文音频各调用两次：10.588 秒样本耗时 0.278 / 0.227 秒；38.336 秒样本耗时 0.592 / 0.387 秒。长样本覆盖完整开头和结尾，保留一千二百元、不要、API、MCP 等内容，存在“第四。”这类标点误差。
- 上述时间是单请求环境的网关往返实测，可能受服务缓存影响，不是浏览器端总延迟、并发指标或真人识别准确率。未使用用户麦克风。

部署与正式浏览器验收结果在完成后补充。
