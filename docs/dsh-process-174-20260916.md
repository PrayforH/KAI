# 174 会话过程展示调整（2026-09-16）

## 改动与原因

此前详细模式展开的是运行环境、权限、工具连接等系统事件；Claude SDK 适配层没有映射模型的 ThinkingBlock / thinking_delta，因此无法显示模型实际返回的思考内容。纯文本回复没有工具动作时，简化模式没有可展示项，但仍提供展开按钮。

本次参考 [DeepSeek Harness 的 ReasoningRow](https://github.com/deepseek-ai/deepseek-harness/blob/0d1f50007f9bca3f52b06e1c3074fa14d5fb0720/packages/client/ui-chat/src/client/chat/ReasoningRow.tsx) 的独立思考行、单行预览与展开交互，按现有组件实现，没有复制其组件代码。

- 移除“正在输出回复…”和答复区的详细过程开关。
- 在个人设置 → 配置加入“展开详细思考过程”，沿用现有浏览器偏好、同页与跨标签同步。
- 模型返回的思考内容单独成行：简化模式为可展开预览，详细模式展开全文并逐项显示工具动作。
- 两种模式均去除常规环境、权限、连接等系统日志，保留真实工具动作、进度说明、失败与能力降级信息。
- 模型仍在处理且尚未开始最终回复时，对最后一个工具动作应用从左到右的暗色扫光，包括刚完成的最后一个工具；等待审批、失败和结束后停止。支持减少动态效果设置。
- 无实际过程内容时不显示展开箭头，不渲染空展开区域。
- 新增 reasoning.delta 映射并保留思考块 ID；50ms 刷新小块，块切换时刷新尾部，去除流式事件与完整 AssistantMessage 的重复；不把 SDK signature 放进展示事件，不混入最终答案。

只有模型实际返回的数据才能展示。历史运行没有记录思考内容，不回填；模型不返回思考时不显示占位思考区。
