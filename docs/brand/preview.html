01

名称 · Mecha 智能体机甲

NAMING

命名铁律（两轮评审沉淀）

第一轮否 AXIS：听不出品类；第二轮否 Agentline：线的意象不足。铁律：名字要自己说出「给谁用、管什么」。Mecha 一听就懂：组装出来的、能干的大家伙。

机甲叙事

组装：平台把模块装成机体——即 Manifest 的确定性 Bundle；驾驶舱：关键动作由人决策——即审批/暂停/恢复；出厂放行：试车过门禁才能晋级——即 Eval/质量门禁。

风险与规避

语气偏玩心 → 企业语境一律带描述符 AGENTOPS CONTROL PLANE 压稳；对外全称 Mecha · 智能体机甲；游戏/玩具类同名多但软件治理类无巨头，注册前仍需第 9/42 类检索。

中文述名

对外全称 Mecha · 智能体机甲；一句话介绍沿用控制台文案「面向组织的智能体任务、能力与运行治理平台」；口头即叫「机甲」。子系统按部件命名，随模块发布逐步启用。

02

标志 · 机甲头与护目轴

MARK
主推 · A

机甲头 · 护目轴COCKPIT

横向圆角机体 = 组装完成的机甲头盔（驾驶舱）；绿轴从左入线、贯穿机体即护目镜（驾驶舱视线）、右侧出线，末端脱离一枚节点：放行下线的机体。保留线上标识的单线笔画与贯穿绿轴 DNA。

备选 · B

轴上合体ASSEMBLY

模块沿绿轴推入组装，完成即以节点离线。组装语义最直给；但图形偏「流水线」，机甲的机体感弱。

备选 · C

合体缝SEAM

两块机体咬合，接缝发光——合体瞬间。构图对称有力量感；但丢了贯穿绿轴的叙事线，与系列标识连续性弱。

03

系统 · 主标规格

SYSTEM
机体：横向圆角方 30×24/64，描边 4.4，与控制台线性图标同语言——不画五官，机体感靠比例
护目轴 = 产线：左右贯通、两端不顶格，是全标唯一彩色；既是驾驶舱视线，也是那条链
脱线节点 = 放行：半笔画间隙，过测的机体离线下线
净空与简化：四周留 1/8 图高；≤16px 换用简化变体（加粗笔画、省略节点）
