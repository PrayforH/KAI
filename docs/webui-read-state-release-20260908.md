## 实现

- 服务端在线程绑定 JSON 中保存 `last_read_at`，键由现有租户、用户、任务组成，不包含设备；旧记录兼容默认空值，无需表结构迁移。
- `PUT /v1/agui/threads/{thread_id}/read` 接收用户实际看到的任务更新时间，服务端限制到现有版本。行锁与单调递增比较保证旧设备的延迟请求不会覆盖新的阅读进度；标题、归档、Session 重绑的事务保持该字段。
- 任务列表返回阅读进度，前端取消 localStorage 作为已读事实源。可见的主对话打开终态任务后提交已读；失败时下一轮列表刷新重试。后台设备通过列表轮询及重新聚焦同步，空闲轮询为现有的 30 秒，并非 WebSocket 实时推送。
- 历史浏览器本地已读记录未批量迁移；没有服务端阅读记录的旧结果首次可能显示未读，打开后开始跨设备同步。
- 每个任务组默认显示最近 5 条，超过时显示“展开显示（N）”，展开后可以“收起显示”。保留原有分组及项目数量展开逻辑。
- 超宽任务标题悬停或键盘聚焦时往返滚动，按实际溢出宽度计算；支持减弱动效设置，保留完整标题提示。移开后恢复原位。
- 智能体构建初次进入及切换构建会话默认打开资产面板，可以手动收起和重新打开。

项目命名、lead-agent 分组仅分析，未修改；联网按用户后续要求已经实现并部署。[分析文档](webui-project-and-web-retrieval-review-20260908.md)。
