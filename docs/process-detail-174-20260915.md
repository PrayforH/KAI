# 执行过程空展开、详细模式与扫光（174，2026-09-15）

## 原因

`displayTimeline()` 的简化规则隐藏了正常基础设施和模型生命周期事件，只保留工具、子任务、异常和公开思考摘要。纯文本回复没有工具调用、也没有思考摘要时，时间线会被过滤为空；组件仍显示可展开按钮和空容器。

另一个问题是主题的 `body.codex-theme-v1 .execution-tree { display: block; }` 优先级高于基础样式的隐藏规则，导致折叠区域仍占空间。

这是前端展示问题，不意味着模型没有执行记录或可以还原其内部思维。

## 修改

- 折叠区域采用更明确的 `[hidden]` 主题样式，实际移除其布局空间。
- 没有额外过程记录时，展开给出明确说明。
- 展开区域右上方新增“详细过程”开关。默认简化；浏览器保存选择，同页面和其他标签页同步。
- 详细模式按事件顺序显示已记录的生命周期步骤、逐个工具、子任务及可公开的思考摘要，工具结果仍可展开查看。不从原始 metadata 提取内部思维，不推测没有返回的摘要。
- 未返回思考摘要时明确说明，仍可查看实际执行步骤。
- 正在处理的当前动作或底部状态行加入从左到右的暗色文字扫光。正文开始输出、审批等待、执行结束时停止；遵循 `prefers-reduced-motion`。
- 时间线使用 memo，计时器跳秒时不重新计算全部过程列表。没有新增接口或轮询。
