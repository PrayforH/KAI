# 产出物面板拖动展开与收起

此历史发布已由[拖动边界与回复图片修复](artifact-inline-and-snap-174-20261008.md)更新。当前版本会提前完整展开，避免对话被挤成半截，并直接在回复中展示图片。

已发布到 https://172.20.109.174/，实现提交 `f0202de60a700c61141f1e3d6b1fc8d856436824` 已推送 develop。

桌面端拖动产出物面板左侧边缘，可以连续调整宽度。拖到距对话区左端 64px 以内后松手，自动占满对话区；向右缩至 180px 以下后松手，直接收起。全宽状态可以拖回普通宽度。展开或收起不覆盖保存的普通宽度，重新打开时恢复普通宽度。双击恢复默认，Escape 取消拖动；方向键微调，End 展开，Home 收起。

沿用现有展开布局，导航栏保留，对话组件继续挂载。HTML 预览在拖动期间暂停接收指针，避免 iframe 截断拖动；松手恢复交互。输入框内容、文件选择和预览状态保留。窄屏沿用原有展开/收起按钮。
