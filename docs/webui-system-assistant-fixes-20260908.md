# 系统助手、联网配置与任务列表修复

日期：2026-09-08。承接本日联网发布与 174 → 79 数据迁移；本次同时更新 172.20.109.174:3501 和 172.20.105.79:3501。

## 任务列表决策

lead-agent 是系统默认通用助手，不代表用户创建的独立项目。再放一层 lead-agent 文件夹会增加导航层级，也容易让用户把系统实现名称当成项目。因此按用户最新授权，将其任务直接列在“任务”栏下；业务智能体继续按组展示。这是展示结构调整，没有创建项目/文件夹数据模型，也不改变任务归属、权限和历史。

通用任务和每个业务分组超过 5 条折叠。展开/收起文字使用与任务标题一致的布局；长标题悬停滚动、减少动态效果偏好、用户级已读同步继续保留。

## 修复和使用方式

- 平台能力目录曾只给系统维护的目录追加 WebSearch/WebFetch。管理员修改过目录后，这两个选项缺失。本次只补齐缺失的内置联网能力，保留既有模型路由、目录内容及维护人。
- Tools 与知识库新增“公开联网”区域，可分别选择 WebSearch、WebFetch，保存并发布后生效；无需配置 MCP。MCP 继续保留。内置联网目前支持 Claude SDK。
- 自定义算子默认收起，由同一卡片右上角“更多”打开。
- 新版 lead-agent 为 1.0.2，包含 WebSearch/WebFetch 和 7 个实际打包的技能：通用任务编排、证据报告、研究综合、交付核验、文档表格制作、技能质量改进及 skill-creator 别名入口。
- 新建通用任务不再沿用上一条 lead-agent 任务的旧版本。旧对话提供“升级并继续此对话”，继续使用原任务记录，通过既有运行时版本切换机制建立新会话；不批量改写旧快照。
- 智能体管理页增加系统助手只读卡片，显示平台版本、进入对话及新建个人智能体入口。需要定制行为时创建个人智能体，不直接修改系统助手。
- 普通个人智能体仍以自身已发布配置决定是否联网；不会给所有存量/新建业务智能体强行授权。使用内置工具时在“公开联网”勾选并发布；构建助手生成的配置也以最终发布内容为准。
- 输入 `$技能名` 即可显式使用技能，不要求先点蓝色提示。自然语言也可描述需求。快捷列表仅列当前智能体实际包含的技能；系统助手已补充创建及优化技能。普通文本不再重复生成蓝色标签，来自技能页面的上下文入口仍有可移除提示。
- 修复任务目录刷新丢失技能的问题：数据库精简投影在服务器端提取技能名称与说明；不返回技能正文、资源文件或整个 Agent 包。内存适配器保持相同语义。
