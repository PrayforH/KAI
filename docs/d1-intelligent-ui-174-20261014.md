# 174 Intelligent UI：接入 d1 自动选型

2026-10-14 已部署到 172.20.109.174。API 和 3 个 worker 均健康。

## 本次行为

主模型先完成回答和工具调用。对于现有结构投影识别出的工具记录结果，平台调用 `d1-3B`，判断本轮需要文字、表格、图表还是方案对比。选择仅影响自动展示；回答正文和业务工具授权保持现有流程。

主模型明确生成的 `harness-ui` 组件保留原选择，不再调用 d1。流程图、时间线、指标、表单和生成式 HTML 仍走现有主模型协议。本期未将 d1 接到生成式 HTML 的需求判断。

数据形状沿用已有入口：至少 5 条记录、最多 200 条、2–6 个可展示标量字段。图表要求真实完整的数值列和非空唯一字符串标签；常见 id、uuid、code、编号、序号不作数值指标。对比要求最多 8 个对象和相同维度。更少记录仍可由主模型直接生成明确组件。

## 请求、数据和偏好

程序先构造并校验可用展示形式。d1 只输出 `{"kind":"…"}`，不生成数据、代码、配置或动作。图表与对比组件由原始完整记录转换，保留数据来源和 presentation_id。

请求中明确的本次展示要求优先于长期偏好。只读取当前租户、用户、智能体和智能体所有者范围内，未到期且 ACTIVE 的展示类 PREFERENCE；最多 4 条。FACT 和无关偏好不参与。偏好内容及其适用条件作为不可信数据提供，不授予任何执行权限。

新增可选 Run input：`ui_presentation_mode=text` 禁用本轮组件；`ui_presentation_kinds` 可进一步收窄自动展示类型。未新增前端设置入口。

## 失败和历史一致性

默认不配置模型时沿用旧流程。启用后最多并行判断现有两个自动候选，单次总超时 3 秒。超时、服务异常、unknown、额外字段、截断输出或选择不支持的类型，回退原有可用表格；不允许的表格则不发布。

最终选择写入现有 Publication 快照。实时终帧前发布最终组件，刷新历史直接回放快照，已存历史不重新调用 d1。运行中历史暂不发布未经判断的自动表格，主模型明确组件保留原投影。
