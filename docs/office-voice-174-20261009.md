## 本地 Codex 核对

静态读取 `/Applications/ChatGPT.app/Contents/Resources/app.asar` 中的 `webview/assets/app-initial-61c077dcc1af.js`，与前一日提取文件逐字节一致。以下是安装包客户端的实现，不能视为闭源云端处理的完整说明：

- 流式听写使用 AudioWorklet、单声道 PCM16，通过 `session.start`、`audio.append`、`session.close` 发送至听写服务；支持原生麦克风采集和浏览器采集分支。

- 客户端函数 `yjr` 计算 RMS 和峰值，RMS 目标 0.063，增益最高 4，峰值限幅 0.708，增益上升平滑系数 0.35。RMS 低于 0.003 时增益回到 1。
- 低 RMS 音频仍转换并上传，不是低音量丢弃门限。`audioHasSignal` 用于纯静音时的恢复判断。
- 流式听写配置未公开模型名称，也未在这段客户端链路看到目标声纹筛选。不能据此证明云端未使用其他降噪或说话人处理。

OpenAI 公开 Realtime API 支持在 VAD 和模型之前降噪，并区分耳机等近场麦克风的 `near_field` 和笔记本等远场麦克风的 `far_field`。这仅说明公开 API 能力，不代表上述 Codex 听写服务实际使用了哪个模式。[官方说明](https://developers.openai.com/api/reference/resources/realtime/subresources/calls/methods/accept)
