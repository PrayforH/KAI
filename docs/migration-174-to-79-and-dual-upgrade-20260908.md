## 新建智能体的联网行为

| 创建或运行方式 | 当前行为 |
| --- | --- |
| 新建主对话 | 默认系统 lead-agent 1.0.1 声明 WebSearch、WebFetch，直接可用 |
| 手动新建智能体 | 默认草稿没有勾选上述两项，可在工具配置中选择后发布 |
| 根据任务生成智能体 | 当前默认工具集合也不包含上述两项，需在草稿中选择后发布 |
| 导入智能体 | 沿用导入清单中的工具声明和运行时兼容性校验 |
| 已有智能体／历史任务 | 沿用所绑定已发布版本的工具配置，不篡改历史版本 |

启用后复用平台搜索服务，无需为每个智能体单独配置 MCP；原有 MCP 继续保留。只读公开搜索／网页读取自动允许，敏感参数、内网、元数据等边界照常检查。该内置实现当前支持本地／延迟执行的 Claude SDK 路径，不支持远程 CLI 或 Codex 运行时；其他路径继续使用已有 MCP。

没有新增用户侧联网总开关。“默认没有声明内置联网工具”不等于操作系统级断网；已有 Bash 等工具的网络边界另见此前联网发布记录。
