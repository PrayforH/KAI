## 行为

- 主对话和效果验证使用公共 Composer 问答卡片。模型通过 `harness-input` 结构化正文提出 1–4 个问题，支持单选、多选、手动填写和补充说明。仅最新、已完成、尚未回答的助手消息显示可提交卡片。选择不预填，不自动提交，也不调用模型声明的操作。
- 答案作为普通用户消息继续当前对话，未发送的输入框内容保留。提交失败保留答案，提交中防重复。历史正文显示可读问题与选项；流式输出时隐藏未完成的 JSON。
- 真实模型会在结构化块之后追加解释，因此允许一个有效块前后有普通说明；多个块、非法结构、重复问题 ID、重复选项或超出长度限制均不生成可提交卡片。
- Claude SDK、DeepAgents、Codex runtime 使用公共 execution contract 指导生成问答卡片。卡片仅用于补充信息；工具审批继续使用现有审批链路。
- 追问队列每条固定一行，末尾直接显示调整方向、删除、编辑图标；取消独立的计数标题行与“更多”菜单。编辑在同一行，保留中文输入法保护；Alt + 上下箭头可调整顺序，已发送待确认项禁止编辑/删除。暂停后的继续按钮按状态显示。
- Builder 修复“启用/关闭联网”“绑定知识库”“启用技能”等入口识别。启用联网返回实际 WebSearch/WebFetch 配置，而非只修改提示词或声称已完成。
- 对话支持原有名称、说明、提示词、任务约定、内置工具、MCP、技能编辑/安装，以及知识库绑定、模型、Python 算子、协作角色、运行时、工具加载方式、运行限制、工作区设置、执行环境、权限策略绑定和验收设置。新增资源须来自当前用户可见目录，应用时重新验证资源可见性及目录修订；模型连接、凭据、知识库/MCP 服务注册仍在资源页面完成。
- 配置建议先展示可编辑卡片，选择应用后才修改草稿。运行与发布仍是独立操作。嵌套的模型、运行限制和工作区字段合并时保留未修改值；原有编译和权限校验不放宽。
