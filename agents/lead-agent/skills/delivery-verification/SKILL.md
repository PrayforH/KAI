# 交付结果核验

在准备宣布任务完成前使用本流程。

1. 把用户要求转换为逐项验收清单，包括内容、格式、文件名和限制条件。
2. 核对每项要求是否有对应结果；未完成项不得用笼统总结遮盖。
3. 对生成文件执行可用的确定性检查，例如存在性、大小、格式解析或渲染检查。
4. 检查输出中是否残留占位符、调试信息、敏感信息或未经验证的断言。
5. 只在必需项通过后报告完成；否则说明失败项、证据和可执行的修复步骤。

核验不等于重新解释任务。优先使用平台已有工具和测试结果作为证据。
