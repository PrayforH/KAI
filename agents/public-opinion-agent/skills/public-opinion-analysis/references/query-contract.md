# 专用舆情查询契约

## 1. 识别意图

### 固定术语消歧

- 本 Agent 的“涉非”只表示“涉及非法集资及相关非法金融风险”，不表示“涉及非洲”。
- 用户未明确提及非洲时，不得生成“非洲”“Africa”、非洲国家或地区等查询词和地域条件。
- 将“涉非”归一化为“非法集资/非法金融风险”，再与主体、产品、事件和风险议题组合；不得把“涉非”作为孤立歧义词交给关键词扩展工具。
- 关键词拆分工具若返回非洲语义候选，必须剔除并记录为歧义纠偏，不能进入最终条件。

- **只构造条件**：输出拟用条件和待确认项，不执行数据查询。
- **普通舆情查询**：按关键词、地域、排除词和时间窗查询内容样本或统计。
- **热搜查询**：保留关键词中的地域表达，除非热搜工具另有独立地域参数。
- **材料分析/公网检索**：不套用专用平台的覆盖范围和指标名称。

## 2. 检查工具

检查当前任务实际提供的专用舆情 MCP 工具，包括关键词拆分、行政区划解析、内容查询、统计和热搜。不要假设工具名，也不要调用未注册能力。

如果存在关键词拆分工具，必须在专用数据查询前先调用它，根据返回候选构造最终条件。存在行政区划解析工具时，通过工具获取编码；不得凭记忆猜编码。

## 3. 归一化字段

- `keywords`：主体、产品、事件、别名和议题组成的布尔表达式。
- `region_codes`：行政区划解析工具返回的编码。
- `exclude_terms`：招聘、广告、无关同名等需要排除的词。
- `time_window`：明确的开始和结束日期/时间，注明时区。
- `language`、`source_scope`、`sort`：只有工具支持且用户需要时设置。

普通舆情查询中，将明确的省市区名称从关键词移入 `region_codes`；关键词和地域之间按 AND 关系解释，`exclude_terms` 为否定条件。关键词或地域至少一项非空。热搜查询不自动移除关键词里的地域词。

不要自行发明工具语法。布尔表达式示例仅用于向用户解释逻辑：

```text
(小米汽车|小米SU7|小米YU7)&(门店|直营店|体验店)&(负面|投诉|问题|故障)
地域：通过行政区划工具解析“北京”
排除：招聘
时间：最近 30 天换算后的绝对日期范围
```

## 4. 执行前复核

确认：

1. 主体别名没有漏掉，也没有加入明显歧义词。
2. 普通查询的地域词已移出关键词；热搜查询按工具规则保留。
3. 排除词不会误伤关键内容。
4. 相对日期已换算为绝对时间。
5. 实际工具参数符合工具 schema。

## 5. 查询后记录

记录实际工具名和参数、返回总量、当前页/样本量、是否截断、排序方式、错误及重试。保留每条具体内容的原始 URL。复核结果是否与查询意图匹配；明显跑偏时先修正条件再分析。

当工具响应存在 8KB/条数/页数上限、游标、`has_more`、`next_page` 或总量大于当前返回量时，不得把当前页当全量。优先按工具 schema 继续分页；无法分页时按主体、日期或地域拆分查询并基于稳定标识/URL 去重。报告必须同时写明“平台总量（若返回）/实际获取量/未覆盖范围”。

## 6. 无专用工具时降级

明确写出“当前未接入专用舆情数据源”。可以：

- 基于用户材料分析；
- 输出建议查询条件，供用户在外部平台执行。

不得声称完成了专用舆情平台、社交平台、全网或内部数据库查询，也不得生成虚假的平台指标。
