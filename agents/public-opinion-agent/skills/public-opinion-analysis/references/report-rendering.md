# 报告渲染规范

仅在用户明确要求文件、HTML、表格或图表时读取并执行本规范。

## 输出位置

- 最终文件名必须反映本次分析对象，不得使用 `public-opinion-report`、`report` 等通用固定名称。
- 优先从已经确认的主要分析主体提炼名称；没有明确主体时，使用简洁的事件或议题名称。不要把整段用户指令直接用作文件名。
- 文件名格式：`outputs/<主体或事件>-舆情风险分析报告.html`；纯文本使用相同主文件名和 `.md` 扩展名。
- 示例：分析“喜来鹿”时使用 `outputs/喜来鹿-舆情风险分析报告.html`；分析多个主体的同一事件时可使用 `outputs/<事件名>-舆情风险分析报告.html`。
- 安全规范化：移除路径分隔符、控制字符、`..` 以及 `<>:"|?*`；连续空白压缩为一个短横线；去掉首尾句点、空白和短横线；主体或事件部分最长 60 个字符。
- 无法可靠提炼主体或事件时，回退为 `outputs/舆情风险分析报告-<YYYYMMDD>.html`，日期取本次分析基准日。
- 中间数据、脚本和抓取缓存放在 `outputs/` 之外。
- 依赖平台原生产物收集/发布；不要直传对象存储或写入旧版固定卷路径。

## HTML

- 生成可离线打开的单文件 HTML，使用 UTF-8、语义化标题和清晰目录。
- 表格使用固定布局、边框、交替行色和自动换行；长 URL/长文本允许断行，不能撑破页面。
- 用颜色徽标区分风险等级或核验状态，但同时保留文字标签，避免只靠颜色传达含义。
- 每条具体内容链接到完整原始 URL；外链使用安全属性。
- 不加载远程脚本、字体或样式依赖。

## 图表

- 只有数据口径可靠且图表确实提升理解时才绘制。
- 将图表以 base64 data URI 嵌入 HTML；使用透明背景、深色文字和可读标签。
- 标注指标定义、时间窗、样本量和来源，不用饼图或情感图伪装不具代表性的样本。

## 脚本与校验

- 确有必要的复杂数据处理或渲染逻辑可在最终文件写入前通过脚本执行，并遵守平台审批。
- 使用 Glob 确认最终文件；使用 Read 抽查文件开头；使用 Grep 检查 `</html>`、原文链接、必要章节和本地路径。
- 在隔离沙箱中，可用平台自动放行的低风险只读 Bash 补充校验，例如 `pwd`、`ls`、`wc`、`head`、`tail`、`grep`、`rg`、`cut`、`stat` 和校验和命令。
- 不使用写入重定向、命令替换、解释器、联网、进程控制、删除、提权或工作区外路径。无法静态证明安全的 Bash 仍会进入审批。
- 没有专用解析工具时，只陈述已完成的结构检查，不声称完成严格语法解析。

- 交付前确认原文链接完整且没有本地绝对路径或敏感值。
- 回复中给出与实际文件完全一致的最终产物路径和文件名，不把中间文件当作交付物。
