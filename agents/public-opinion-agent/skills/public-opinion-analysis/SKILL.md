# 舆情分析工作流

## 术语边界

在本业务中，“涉非”固定指“涉及非法集资及相关非法金融风险”，不指“涉及非洲”。除非用户明确提出非洲国家、地区、机构或事件，任何关键词拆分、同义词扩展、地域解析、查询参数和报告都不得加入“非洲”“Africa”或非洲地理概念。收到“涉非”时先归一化为“非法集资/非法金融风险”，再与已确认主体或事件组合，不能把“涉非”作为孤立歧义词直接扩展。

1. **预检（强制）**：读取本 `SKILL.md` 和 `references/query-contract.md`。未成功读取时不得调用 MCP 或形成正式报告。
2. 明确主体、主体别名、事件、绝对时间窗、地域、语言、排除项、数据范围与交付形式。只有缺失项会改变查询或结论时才追问。
3. 选择最窄的数据路径：用户材料 → 已注册的 `sentiment_query_mcp` 专用查询。不要用模型记忆或局部样本冒充专用平台或全网数据。
4. 先列查询覆盖矩阵：目标、工具、条件、时间分片、页码/游标、预期字段。检查运行时实际工具 schema 后执行，不猜工具名或参数。
5. 对 8KB/条数/页数截断、游标或 `has_more` 做显式处理：继续分页，或按主体/日期拆分后合并去重。记录总量、已取量和未覆盖范围；不得把第一页当全量。
6. 建立证据台账：来源编号、来源类型、发布者、完整 URL、发布时间、抓取时间、查询参数、独立/转载关系、支持/反证结论与可信度。
7. 合并转载和近重复内容，将事实陈述、归因观点、分析推断和未决不确定性分开。重要事实尽量由两个独立可信来源交叉验证；做不到时标注“单一来源”或“未证实”。
8. 建立事件时间线与议题矩阵，聚类叙事和立场，识别关键传播节点。只有数据集和采样方法支持时才报告占比、趋势、热度和覆盖范围。
9. **风险研判（强制）**：读取 `references/risk-rubric.md`，逐项说明证据强度、受影响方、传播特征、已验证影响、不确定性以及升级/降级信号。
10. **正式交付（强制）**：读取 `references/report-contract.md` 并逐节写作。每条具体帖子或报道都链接原文；不得用结果页代替原文。
11. **交付自检**：核对章节、证据编号、反证、时间线、原文链接、查询分页/截断和数据盲区。缺失章节必须写明“证据不足/不适用”及原因，不能静默省略。

## 深度标准

- 内容充足的专项分析应形成“结论 → 支持证据 → 反证/冲突 → 证据强度 → 风险含义 → 建议动作”的闭环，而不是把 MCP 返回压缩成几段摘要。
- 执行摘要只负责导读，不能替代正文。正文至少覆盖报告契约中的全部适用章节；查询过 MCP 必须保留查询附录。
- 对数据不足的主题，不得靠常识扩写或重复凑篇幅；应明确指出还需要哪类数据才能升级结论。

## 产物

- 默认直接在对话中回答。
- 用户明确要求文件、HTML、表格或图表时，必须读取 `.claude/skills/public-opinion-analysis/references/report-rendering.md`，把唯一最终交付物写入 `outputs/`。
- 最终报告校验优先使用 Glob、Read 和 Grep；也可使用平台自动判定为低风险的隔离沙箱只读 Bash，不要为了绕过策略改写命令。
- 优先使用平台原生工作区、产物发布和记忆能力，不迁移旧版对象存储上传、固定卷路径或自建用户记忆写入。
- 只把稳定且有长期价值的偏好提交给 consent-gated memory 工具；不保存秘密、个人敏感信息或一次性任务细节。

## Reference 路径

调用 Read 时使用上述 `.claude/skills/public-opinion-analysis/references/...` 工作区相对路径，或直接使用 Glob 返回的相对路径。不要把路径展开为 `/root/.claude/skills/...`、`~/.claude/skills/...` 或其他 HOME 绝对路径。

## 当前版本边界

`0.3.22` 声明 `sentiment_query_mcp`，但知识库保持为空，也未声明公网搜索。只能调用运行时实际提供的 MCP 工具；连接失败时退回用户材料和工作区证据并明确数据缺口。

## 禁止事项

不执行发帖、删帖、封禁、账号查询、开盒或对外联络。不虚构情感比例、传播量、趋势、行政区划编码或“全网覆盖”。
