# 数据本体问数助手

通用固定 Agent，使用时选择数据源。方法来源为用户提供的小树 1.1 `sapling-data-agent-customizer` 原始提取（2026-10-14）。KAI 适配保留实体粒度、归并检查、值域、关系基数、指标目录、九章本体与口径迭代；移除小树项目创建/参考树 API 和运行时绝对路径。

文件分析使用 Python 标准库 SQLite 只读执行器；CSV/XLSX 导入分析副本。0.2.1 绑定平台的 database-readonly MCP，统一支持 MySQL、PostgreSQL、达梦和 SQLite；可选预置数据源，也可使用用户授权提供的主机、端口、用户名、密码、库/Schema，通过 connect_database 建立临时只读连接。本包不携带数据库凭据；达梦采用独立服务内的官方 dmPython 驱动，不依赖原环境的私有 dmq。

会话内通过工作区快照接续本体，跨会话通过导出的本体资产迁移，不共享用户数据。现有平台文件大小/快照限额仍适用。生产库写入禁止；允许隔离工作区的分析与产物写入，因此使用 production-standard 策略。

与原方法有意修正：不把密码保存到数据源.md；不以 DB > DOC 简单覆盖业务定义；同构表/不相交 ID 不自动证明可归并；LIMIT/count(*) 不作为低成本保证；先记录候选、确认后生效；不声称普通 Bash 能强制保证数据库只读。

验证包括包门禁、SQLite 查询/写入拒绝/超时/截断/原件不变，以及真实模型的 fan-out 样例、缺源澄清和拒绝写库。上线记录另见发布报告。
