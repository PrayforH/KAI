# Code view themes

Codex Dark and Codex Light TextMate theme definitions, aligned with the local Codex desktop reference (26.908.40834). Source files are rendered by `@pierre/diffs`; the project tree uses `@pierre/trees` and the same theme colors.

The source viewer is read-only. It displays the exact DeepAgents export files for the saved draft revision; it does not imply Git changes or provide source-to-draft synchronization.

UI typography follows the reference: system UI font, system monospace code at 12px / 1.8 line height, and 29px file tree rows.
